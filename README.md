# Distributed and Parallel Computing

A collection of practical concurrency work in Java and Python. The projects compare process-based and thread-based execution and apply synchronization concepts in a concurrent card-game simulation.

## Included work

- Parallel sum implementations using processes and threads in Java and Python.
- A concurrent card game with shared state, participants and a moderator.
- Source-focused folders with generated build files excluded.

## Tools

Java, Python, processes, threads, shared state and concurrency fundamentals.
